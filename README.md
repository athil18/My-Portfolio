# Unified MHD Project: Showcase & Portfolio

This repository contains the complete "MHD Commerce" e-commerce engine and the "Portfolio" showcase application.

## 📂 Project Structure

- **[ecommerce/](./ecommerce)**: A full-stack MERN e-commerce platform with Glassmorphism UI, secure payment flow, and admin dashboard.
- **[portfolio/](./portfolio)**: The master portfolio application featuring personal projects, skills, and the integrated e-commerce showcase.

## 🚀 Quick Launch

To launch both applications simultaneously, use the provided batch script:

1. Open the `ecommerce` folder.
2. Run `launch-suite.bat`.

## 🛠️ Tech Stack

- **E-commerce**: React 19, TypeScript, Node.js, Express, MongoDB, Tailwind CSS v4, Stripe.
- **Portfolio**: React, Bootstrap, Particles.js.
