## 🔗 How to Upload to GitHub
1.  Create a new repository named `mhd-commerce`.
2.  Initialize git in your root folder: `git init`.
3.  Add all files: `git add .`.
4.  Commit: `git commit -m "Initial commit of MHD Commerce project"`.
5.  Link to GitHub: `git remote add origin [YOUR_REPO_URL]`.
6.  Push: `git push -u origin main`.
